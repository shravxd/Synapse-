# ⚡ Synapse

*A modern influencer marketing platform that connects brands with digital creators across India, enabling seamless campaign discovery, collaboration, and management through a unified interface.*

![Dashboard](assets/Synapse.png)

## 🛠️ Status
**Frontend Prototype (UI Shell)** built using mock data, ready for backend integration.

## ✨ Features

- **Centralized Navigation** for Influencers, Campaigns, and Dashboards
- **Analytics Dashboard** displaying key platform metrics
- **Category-Based Discovery** across Technology, Beauty, Fitness, and Cuisine
- **Cross-Platform Influencer Search** with social media filters and engagement insights
- **Campaign Launch Workflow** for discovering, launching, and tracking campaigns
- **Responsive Dark-Themed UI** optimized for all devices

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS, CSS
- **Icons:** React Icons, Lucide React
- **Environment:** Node.js

## 🎯 Goal
To simplify influencer marketing by providing brands and creators with a single platform for discovery, collaboration, and campaign management.
